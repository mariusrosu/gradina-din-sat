# Gradina din Sat — Platformă Web de Prezentare

**Gradina din Sat** (`Cătană Daiana Mădălina PFA`) este un site web static de prezentare dedicat promovării produselor agricole de calitate superioară și prezentării fermei de familie din comuna Silivașu de Câmpie, județul Bistrița-Năsăud.

---

## 🌾 Scopul Proiectului

Proiectul are ca scop furnizarea unei prezențe online moderne, profesionale și accesibile pentru ferma agricolă **Gradina din Sat**. Platforma este concepută pentru:
- **Prezentarea culturilor agricole principale:** Porumb zaharat, fasole verde, roșii și ardei, cultivate responsabil și recoltate la maturitatea optimă.
- **Promovarea valorilor și identității fermei:** Istoria unei afaceri de familie dezvoltate cu respect pentru pământ, având la bază pregătirea de specialitate a tinerei fermiere (absolventă a Facultății de Știința și Tehnologia Alimentelor din Cluj-Napoca).
- **Evidențierea sprijinului european (AFIR):** Prezentarea proiectului de finanțare europeană **„Instalarea Tânărului Fermier”** (obținut în anul 2023), prin care ferma a fost modernizată și dezvoltată sustenabil.
- **Facilitarea contactului direct:** Oferirea tuturor datelor de contact pentru comenzi și colaborări.

---

## 📁 Structura Fișierelor

Site-ul este realizat în HTML5 și CSS3 pur, fără dependențe externe sau framework-uri complexe, fiind extrem de rapid și ușor de întreținut:

- `index.html` — **Pagina principală (Acasă):** Conține secțiunea Hero, prezentarea celor 4 produse principale și galeria foto cu imagini din gospodărie.
- `about.html` — **Despre noi:** Povestea fermei, studiile de specialitate și detaliile despre proiectul european de modernizare.
- `contact.html` — **Contact:** Casetele cu datele de identificare ale PFA-ului, telefonul de contact, adresa de e-mail și adresa fizică a fermei.
- `styles.css` — **Fișierul de stiluri partajat:** Sistemul de design cu culori naturale, tipografie Google Fonts (Fraunces & Spline Sans), layout responsiv și animații subtile.
- `images/` — **Directorul cu resurse vizuale:**
  - `logo-afir.png` — Logo-ul Agenției pentru Finanțarea Investițiilor Rurale (AFIR).
  - `rosii-lada.jpg` — Imagine cu roșiile proaspăt culese în lădițe.
  - `cimp-apus.jpg` — Imagine panoramică cu câmpul la apus de soare.
  - `spic-apus.jpg` — Imagine de detaliu din culturile fermei.
  - `floarea-soarelui.jpg` — Imagine cu câmpul de floarea-soarelui.

## 🚀 Previzualizare și Găzduire

### Previzualizare locală
Nu este necesar niciun pas de compilare sau instalare de pachete. Pentru a previzualiza site-ul, deschideți fișierul `index.html` în orice browser web.

### Publicare online (Găzduire gratuită)
Site-ul poate fi găzduit gratuit pe orice platformă pentru fișiere statice:
- **Netlify:** Trageți întregul folder pe [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages / Cloudflare Pages:** Conectați depozitul Git pentru publicare automată.
